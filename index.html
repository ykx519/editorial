API 接口设置

OpenAI 兼容接口，切换厂商只换三处
高级选项（接口地址覆盖 / CORS 受限时使用本地代理）

部分厂商接口不允许浏览器跨域直连。若请求被 CORS 拦截，可在此填入本地代理地址，或用 测试连接 按钮确认连通性。

密钥仅写入本机 localStorage，不上传、不写入文件、不随提示词外发。请勿把密钥硬编码进提示词或提交到仓库。

三

外接 API 生成社论

调用上方接口，按提示词产出成稿
成稿输出区。点击「生成社论」开始。

成稿应包含主标题、导语、三个分论点、措施部分、尾声、信息来源与备选标题。可将输出粘贴到 文章评分 页做综合评分。

四

图片插入与来源注记

标题图 · 各章节图 · 结尾图，结尾按插入顺序注记来源

尚未添加图片。建议至少包含标题图（主题/导语相关）、各章节图与结尾图。

本地图片自动转为 base64 内嵌，成稿 HTML 保持单文件、双击可开。建议单张图片不超过 1MB。图片按插入顺序编号（图1、图2……），结尾自动生成「图片说明」注记来源。

五

来源链接补全

超链接或纯文字网址均可，应用后自动链接化并附访问时间

缺链接的条目可点「AI 补链」由模型给出最可能的官方页面（请务必点「搜索核验」确认真伪），或点「搜索核验」打开 Bing 查到地址后粘贴。应用后网址以超链接形式插入并附访问时间，仍无网址的条目会标注待核。默认搜索引擎可换为百度或 Google。
