# 社论·工坊 交付包（社论.zip）

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `prompt_editorial.md` | 可复用《社论写作提示词》模板，【】占位符可替换为具体参数 |
| `editorial_land-finance.html` | 成稿样例页面（主题。土地财政转型），报刊风格单文件 HTML，双击可开 |
| `API接入说明.md` | 外接智能体 API 的接入方式、厂商对照表与调用代码 |
| `index.html` | 生成工作台。提示词生成 + API 接口设置 + 外接 API 生成社论，三者同页 |
| `score.html` | 评分分页面。对社论或申论文章做综合评分，输出可改进点、精彩之处与可学之处 |
| `editorial_output.html` | 成稿修正版示例（主题。新就业形态漏保），已删除备选标题、渲染小标题、来源附链接与访问时间 |

## 使用顺序

1. 双击 `index.html` 打开生成工作台。
2. 在「一、提示词生成」填写议题、核心论点与分论点方向，生成提示词。
3. 在「二、API 接口设置」选择厂商，填写 base_url、模型名与 API Key，保存并测试连接。
4. 在「三、外接 API 生成社论」点击生成，成稿可下载为 `.md` 或渲染为报刊风格 `.html`。
5. 打开 `score.html`（或点页面顶部「文章评分」），粘贴文章，勾选评分维度，先本地体检再 AI 综合评分。

## 评分维度

立意高度、论证逻辑、表述水平、语言风格、结构层次、素材与规范，权重可调，默认合计 100 分。
报告输出。总分与等级、各维度得分与点评、可改进点（3 至 5 条）、本文精彩之处（2 至 4 条）、可学之处（2 至 4 条）。

## 安全说明

- API Key 仅保存在本机浏览器 localStorage，不上传、不写入文件、不随提示词外发。
- 部分厂商接口不允许浏览器跨域直连，可在生成工作台「高级选项」中填入本地代理的完整接口地址。
- 模型评分为辅助参考，重要考试请以官方阅卷标准为准。

## 修订记录（v2）

1. 渲染成稿时自动删除备选标题部分。
2. 修复小标题渲染。`##` 等 Markdown 标记会被转换为真正的标题样式，不再以字面形式显示。
3. 信息来源自动拆条排版，来源类型做成小标签，网页链接以超链接形式呈现并附访问时间；无可访问链接的来源标注待核；提示词与系统提示已强制要求模型给出完整 URL。
4. 评分页接口复用改为自动同步（加载、切回窗口、跨标签页变更时刷新），并提供「同步工作台配置」按钮；base_url 与模型名带默认值（DeepSeek）。

## 修订记录（v3，图片插入）

1. 生成工作台新增「四、图片插入与来源注记」面板，支持添加、删除、上移下移图片，可填 URL 或本地上传（自动转 base64 内嵌，成稿仍为单文件）。
2. 图片分三类。标题图（主题/导语相关，置于主标题下方）、章节图（按插入顺序自动匹配各小节）、结尾图（置于尾声）；支持「一键补齐」生成标题图 + 各章节图 + 结尾图，缺项时提示补齐。
3. 每张图片带图注、来源标注与来源链接，按插入顺序编号（图1、图2……）。
4. 成稿结尾自动生成「图片说明（按插入顺序记录图片来源）」注记，逐条记录图号、位置、图注、来源与访问时间。
5. 渲染后可在页内预览（iframe），下载的 HTML 自带图片与注记。

## 修订记录（v4，来源补链 + Agent 搜图）

1. 新增「五、来源链接补全」面板。解析信息来源逐条列出，缺链接条目支持「AI 补链」（模型给出最可能官方链接，请务必核验）与 Bing / 百度 / Google 一键搜索核验，也可手动粘贴纯文字网址；「应用到成稿并重新渲染」后网址自动转超链接并附访问时间，仍缺的标注待核。
2. 图片支持 Agent 搜图。「AI 配图方案」按文章自动生成标题图、各章节图、结尾图的搜索关键词与图注；「一键自动配图」按关键词从开放图库（Openverse + Wikimedia Commons）自动搜索并插入图片，来源（作者/许可/页面）自动写入结尾注记。
3. 每个图片位提供「搜开放图库」实时搜索选图，以及 Bing / 百度 / Google 图片搜索跳转（按关键词预填搜索词），搜到后可粘贴链接或上传替换。
4. 上传、URL 填写与替换图片功能全部保留；提示词与系统提示进一步严禁“URL待补”占位文字，要求成稿来源直接写出完整网址。

## 修订记录（v5，生成后自动化）

1. 新增「生成后自动补全来源链接 + 自动配图」开关（默认开启）。点击「生成社论」后自动执行：解析来源 → 逐条 AI 补链 → 写回成稿（超链接 + 访问时间）→ AI 配图方案 → 开放图库自动搜图插入，全程无需手动点击。
2. 自动补链结果仍可逐条用 Bing / 百度 / Google「搜索核验」复核与改写，手动面板功能不变。
3. 链接识别增强。纯文字 `www.` 开头的网址也会被提取并转为可点击超链接（自动补 https://）。
